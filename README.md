# Bowland Next — Система управления оборудованием боулинг-клуба

Современный веб-интерфейс оператора и механика боулинга, заменяющий устаревшую DOS-систему **Qubica AMF Mendes Bowland (1998)**.

## Архитектура и контекст системы

- **Шина LCom (RS-485)**: Управление 12 парами дорожек (до 48 дорожек в зале). Обмен фиксированными кадрами (30/31 байт) на скорости 19200 бод с маскированием XOR и подсчётом CRC (Sum256 / XOR).
- **ESP32/ESP8266 Мост**: Аппаратный беспроводной / Ethernet мост транслирует RS-485 в TCP-сокеты бэкенда.
- **Mock Service Worker (MSW v2)**: Полная эмуляция REST API до развёртывания бэкенда на FastAPI. Все мутации (сброс кеглей, тумблеры опций, новые игры, броски) изменяют in-memory состояние в реальном времени.

## Стек технологий

- **React 19 / 18 + TypeScript (strict mode)**
- **Vite** — быстрая сборка и dev-сервер
- **Tailwind CSS** + **Lucide Icons**
- **shadcn/ui** (Button, Card, Input, Label, Select, Switch, Dialog, Sheet, Tabs, Table, Badge, Sonner, Tooltip, Separator, ScrollArea, DropdownMenu, Form, Skeleton)
- **TanStack Query v5** — серверное состояние и кэш
- **Zustand** — состояние UI (тема, сайдбар, фильтры) и телеметрии связи
- **React Router v6** — SPA-маршрутизация
- **react-hook-form + zod** — строгая валидация форм настроек
- **MSW v2** — перехватчик сетевых запросов в браузере

## Инструкция по запуску

### 1. Установка зависимостей
```bash
pnpm install
# или
npm install
```

### 2. Запуск в режиме разработки
```bash
pnpm dev
# или
npm run dev
```

Приложение откроется на порту `http://localhost:3000`.

### 3. Проверка типов и сборка
```bash
npm run lint    # Проверка TypeScript без эмита файлов
npm run build   # Сборка производственного бандла в /dist
```

## Реализованный функционал

1. **Dashboard (Главная)**:
   - 12 дорожек (4 офлайн, 3 активные с игроками, 5 в покое).
   - Переключение вида: сетка карточек или табличный список.
   - Фильтры: «Все», «В игре», «Офлайн» + мгновенный поиск.
   - Быстрые действия на карточке:
     - Сброс кеглей (с диалогом подтверждения).
     - Переключение Cosmic (УФ неоновый свет).
     - Подъём/опускание бортиков бампера.
   - Индикация активных режимов (Bambini, Cosmic, KbdLock, NoSpeed).

2. **Lane Detail (Управление дорожкой `/lane/:id`)**:
   - Полноценный ScoreBoard с таблицей 10 фреймов для каждого игрока с подсветкой активного хода, страйков (`X`), спеаров (`/`) и заступов (`F`).
   - Интерактивный `PinTriangle`: клик по кегле переключает её состояние (для ручной отладки механиком).
   - Живой JSON-блок `PinState` с кнопкой копирования.
   - 5 тумблеров опций (`bambini`, `cosmic`, `kbd_lock`, `no_speed`, `swap_off`) с мгновенной мутацией.
   - Вертикальный `ShotTimeline` с историей последних 20 бросков, скоростью в км/ч, сплитами и фолами.
   - Вкладки внизу: сырой hex-трафик пакетов шины LCom с валидацией чексуммы, и сохраняемые локально заметки оператора.

3. **Settings (Настройки)**:
   - Выбор транспорта: Serial (порт, бодрейт), TCP Bridge (хост, порт) или Mock.
   - Параметры LCom: XOR-маска, длина кадра (30/31 байт), чексумма (`sum256` / `xor`).
   - Дорожки: 2..48, стартовый номер.
   - Сохранение через PUT `/api/settings` с валидацией zod и тостами Sonner.

4. **Индикатор связи и тема**:
   - В шапке отображается статус аппаратного соединения с ESP32 / COM-портом.
   - Переключатель темы (тёмная/светлая), тёмная тема активна по умолчанию.
